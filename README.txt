# Usman Gani Ansari — Developer Portfolio

## Quick start
1. Extract this ZIP.
2. Open `config.js` in any text editor.
3. Replace the sample email, phone number, LinkedIn, GitHub, LeetCode, skills, projects, education, and experience with your real details.
4. Put your PDF resume in the `assets` folder and name it exactly `resume.pdf`.
5. Keep `assets/profile.png` as your portfolio portrait, or replace it with another suitable portrait using the same filename.
6. Open `index.html` in a browser to preview.

## Important before publishing
- Remove all placeholder text and example repository links.
- Test every social, project, email, and resume link.
- The contact form opens the visitor's default email application with a pre-filled message. It does not send messages through a server.
- The resume download button works once `assets/resume.pdf` exists.
- Publish the folder with GitHub Pages, Netlify, or another static hosting service. Upload the folder contents, not just `index.html`.

## Files
- `index.html` — page structure
- `style.css` — responsive styling, animations, colors
- `script.js` — interactions and rendering
- `config.js` — edit your personal details here
- `assets/profile.png` — professional portrait
- `assets/resume.pdf` — add your own resume here
